# Do Front-end ao Back-end

Projeto desenvolvido durante o desafio
"Treinando uma IA de Aprendizagem" da DIO.

## Objetivo

Compreender o fluxo de comunicação entre uma interface
web, uma API, o servidor e o banco de dados utilizando
o NotebookLM como ferramenta de aprendizagem ativa.

## O que estudei

- Arquitetura cliente-servidor
- HTTP e HTTPS
- APIs REST
- Métodos HTTP
- JSON
- Códigos de status
- Comunicação Front-end e Back-end

##  Aprendizados

Este projeto foi utilizado não apenas para obter respostas
de uma IA, mas para experimentar o uso de IA como ferramenta
de aprendizagem, comparação de fontes e organização do
conhecimento.
