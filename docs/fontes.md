# Etapa 1 - Curadoria de Fontes

Conforme o desafio solicitava, iniciei o projeto selecionando cinco fontes
complementares sobre a comunicação entre frontend e backend.

A curadoria buscou reunir conteúdos sobre protocolo HTTP, arquitetura
cliente-servidor, APIs REST e JSON, permitindo compreender diferentes
etapas envolvidas na comunicação de uma aplicação web.

## 1. HTTP: um guia completo sobre o que é e como funciona o protocolo da web

**Fonte:** Alura

Conteúdo utilizado para compreender o funcionamento do protocolo HTTP,
a estrutura das requisições e respostas e sua participação na comunicação
entre cliente e servidor.

https://www.alura.com.br/artigos/http

## 2. O que é API REST?

**Fonte:** Google Cloud

Material utilizado para estudar o conceito de REST, recursos, endpoints,
métodos HTTP e a comunicação entre diferentes aplicações.

https://cloud.google.com/discover/what-is-rest-api?hl=pt-BR

## 3. Redes de Computadores II — Sistemas Cliente/Servidor & Sockets

**Fonte:** Universidade Federal do Paraná (UFPR)

Material acadêmico utilizado como base para compreender a arquitetura
cliente-servidor, sockets e a comunicação através da rede.

https://www.inf.ufpr.br/elias/redes/19aulaRedes.pdf

## 4. Arquitetura cliente-servidor: como o frontend e o backend conversam na prática

**Fonte:** DIO

Conteúdo utilizado para relacionar os conceitos de cliente e servidor
ao desenvolvimento frontend e backend.

https://www.dio.me/articles/arquitetura-cliente-servidor-como-o-frontend-e-o-backend-conversam-na-pratica-89d75004676a

## 5. O que é JSON?

**Fonte:** Alura

Material utilizado para compreender o JSON como formato de representação
e troca de dados entre diferentes sistemas.

https://www.alura.com.br/artigos/o-que-e-json
